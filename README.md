# LeetCode Problems

My solutions to LeetCode problems, written in **Java**.

This repository is focused on practicing **data structures, algorithms, problem solving, and coding interview skills**.

## 📂 Structure

Problems are organized by difficulty:

```text
leetcode-problems/
├── easy/
├── medium/
└── hard/
```

Each problem has its own directory containing the Java solution and a `README.md` with the reasoning behind the solution.

Example:

```text
easy/
└── TwoSum/
    ├── TwoSum.java
    └── README.md
```

## 📝 Problem Documentation

Each problem has its own `README.md` containing:

* Problem
* Approach
* Step-by-step reasoning
* Time complexity
* Space complexity
* Alternative approaches, when applicable
* Lessons learned

The goal is not only to record the final solution, but also to understand **why the solution works and why the chosen approach is efficient**.
